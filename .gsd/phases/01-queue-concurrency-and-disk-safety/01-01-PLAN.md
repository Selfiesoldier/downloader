# Plan 01.01: Cookieless Extractor Engine & Platform Resolvers

<objective>
Eliminate mandatory user cookie requirements across all supported platforms by implementing modern player client rotation (`visionos`, `android_vr` for YouTube) and automated fallback resolvers (Instagram embed CDN, Twitter `api.fxtwitter.com`, TikTok `tikwm` and `curl_cffi`), and purge cookie management prompts from user-facing Telegram bot commands and welcome messages.

Purpose: Free everyday users from uploading Netscape `cookies.txt` while maintaining 100% extraction success across YouTube, Instagram, TikTok, Twitter/X, and Reddit on residential, mobile, and VPS IPs.
Output: `extractors.py`, updated `bot.py`, and `tests/test_extractors.py`.
</objective>

  <name>Implement CookielessExtractorEngine and platform resolvers in extractors.py</name>
  <files>extractors.py</files>
  <action>
    Create extractors.py with CookielessExtractorEngine containing:
    1. get_cookieless_ydl_opts(url, extra_opts=None):
       - YouTube client rotation using player_client: ["visionos", "android_vr"] with player_skip: ["js", "configs", "webpage"]. Empirically confirmed to return all resolutions (360p to 4K 2160p + audio) with zero SABR bot challenges and zero PO token requirements.
       - Enable youtube_include_dash_manifest: True and check_formats: False for sub-second metadata fetching.
       - Generic headers with modern mobile/desktop User-Agents and Accept-Language headers.
    2. Instagram Resolver Cascade (resolve_instagram):
       - Primary: native yt-dlp with mobile user-agent headers.
       - Secondary: Embed resolver fallback querying public embed endpoints (e.g., eeinstagram / instagramez / public Cobalt instances) to extract direct MP4 CDN links (scontent.cdninstagram.com).
    3. Twitter / X Resolver Cascade (resolve_twitter):
       - Primary: native yt-dlp.
       - Secondary: Fallback to https://api.fxtwitter.com/status/{id} which provides direct CDN MP4 links without requiring API keys or cookies.
    4. TikTok & Reddit Resolvers:
       - Direct extraction with curl_cffi browser TLS impersonation and fallback to public tikwm API (https://www.tikwm.com/api/) for watermark-free MP4 URLs.
    5. Smart Quality Badges (extract_smart_formats):
       - Parse video formats and compute bandwidth-aware badges: ⚡ Fast 720p (~30MB), 🎬 Full 1080p (~150MB), 💾 Data Saver 480p (~15MB), and 🎵 Audio Only (MP3) with estimated sizes for vertical (9:16) and landscape streams.
    AVOID: Relying on web player client for YouTube because it immediately triggers SABR bot verification (HFHl_tXSyaE).
    AVOID: Hardcoding single third-party resolver endpoints without exception handling; all fallbacks must fail gracefully back to yt-dlp.
  </action>
  <verify>python -c "import extractors; opts = extractors.get_cookieless_ydl_opts('https://youtu.be/test'); assert 'visionos' in opts['extractor_args']['youtube']['player_client']; print('extractors.py validated successfully')"</verify>
  <done>extractors.py provides cookieless options, Instagram/Twitter/TikTok fallback cascades, and bandwidth-aware format badge extraction.</done>
